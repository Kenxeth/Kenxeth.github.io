# Reflection

## 1. Flexbox: row vs column

flex-direction: row makes it so that you align the contents within that container horizontal. while flex-direction: column makes it so that you align the contents within that container vertically.

## 2. Why relative units matter

If we were to use pixels the pixels would not scale according to what device we are using so if we were to use like a phone to view our content then it would be awkward compared to a computer if we had it set to a set amount of pixels. Compared to like vh or a % that does scale according to the size of our device.
